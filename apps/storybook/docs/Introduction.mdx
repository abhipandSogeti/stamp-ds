# Stamp Design System

Stamp is a **framework-agnostic design system** built on [Lit Web Components](https://lit.dev). A single
component runtime ships everywhere — Vanilla HTML, React, Angular, or any framework — while a three-tier
token pipeline makes theming and dark mode a one-file swap.

## Accessibility Commitment

Every component targets **WCAG 2.2 Level AA**:

- Built on native HTML semantics — `<button>`, `<input>`, `<label>`, `<fieldset>`
- ARIA attributes applied automatically: `aria-disabled`, `aria-required`, `aria-busy`, `role="alert"`
- Keyboard navigation works without additional configuration
- Colour contrast ≥ 4.5:1 enforced by token values
- **axe-core** runs on every story in this Storybook — check the **Accessibility** panel on any story
